# 한전 사무 면접 노트

한국전력공사 사무직(경북 지역전문사원) 직무면접·경험면접 준비 사이트.
정적 사이트이고 빌드 없이 `index.html`을 열면 동작한다.

배포: https://ayun-jeong.github.io/kepco-interview/

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 섹션 뼈대와 고정 본문(면접 구조, 후기, 조언, 경북, 참고 사이트, 인쇄) |
| `styles.css` | 스타일. 라이트·다크 자동, 인쇄용 규칙 포함 |
| `app.js` | 집계·렌더링. 질문 번호·등급, 검색·필터, 숫자 카드, 연습 타이머, 인쇄 설정 |
| `data/sources.js` | `SOURCES`(질문을 가져온 후기 목록), `REFS`(근거 자료·출처) |
| `data/questions.js` ~ `questions5.js` | `CATS`(질문 유형), `QUESTIONS`(질문 묶음), 후기별 실제 질문 문장 연결 |
| `data/jobdesc.js` | 사무 직무기술서 원문 → 어디서 하는 일 → 말할 거리 → 관련 질문 |
| `data/me.js` | 경험 카드(`ME.exps`, 자소서에 쓴 경험은 `essay: '자소서 n번'`), 30초·1분 자기소개, 경북 지원동기 |
| `data/essay.js` | 제출한 자소서(2026.10.29) 원문, 표시할 구절 `hooks`, 꼬리질문 `qs`(→ `ESSAY_FOLLOWUPS`, id `ef{문항}_{순서}`), 숫자 대조표 `nums` |
| `data/memo.js` | 이슈 암기: 한전 기본·지금 하는 일·시사·상식 사전·영상 정리·숫자 카드 |
| `data/aix.js` | 한전 AI 현황과 내 AI 아이디어 |
| `data/answers_1~7.js` | 질문별 답변 `{s 말할 답변, k 한전 연결, e 내 경험 키, f 꼬리질문 대비}`. 자소서 꼬리질문은 `answers_7.js` |

## 데이터 규칙

- 질문 묶음 하나 = `{ id, cat, q, v: [[출처키, 실제 질문 문장], ...], tip, def?, fix?, link?, star? }`.
- **빈출 횟수는 서로 다른 출처 수**다. 같은 후기 안에서 여러 번 나와도 1로 센다. 등급은 S(10곳 이상)·A(5~9)·B(2~4)·C(1).
- 예상 질문은 `pred: true`와 `basis`(예상 근거)를 둔다. 실제 후기 문장이 붙으면 `pred`와 `basis`가 지워지고 기출이 된다.
- 같은 내용의 질문은 하나로 합친다. 자소서 구절이 기출 질문과 같으면 `hooks`에 그 질문 id(문자열)를 쓴다.
- `cat`은 `CATS`의 `k`와 정확히 같아야 한다.
- 소제목의 개수는 `data-n`으로 데이터에서 센다. 직접 적지 않는다.

## 검증

```sh
node --check app.js
```
데이터를 고친 뒤에는 브라우저 콘솔에 오류가 없는지, 질문 번호 링크(`#q-…`)와 경험 링크(`#exp-…`)가 모두 열리는지 본다.
